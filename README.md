# Flex — витрина студии аналитики

Одностраничный лендинг-витрина для фриланс-студии **Flex** (аналитика и автоматизация для бизнеса).

Статический сайт без сборки: `index.html` + `css/style.css` + `js/main.js`.

## Разделы
- **Hero** — УТП и стек (SQL, Python, Power BI, Excel, Streamlit, LLM).
- **Услуги** — анализ продаж, дашборды, автоматизация, AI/LLM, Streamlit-сервисы.
- **Кейсы** — BizView, Флюкс-калькулятор, Beauty Bot, Академия роста.
- **Как работаю** — бриф → расчёт → реализация → поддержка.
- **Цены** — три пакета.
- **Контакты** — Telegram @SashaShyman, email.

## Локальный запуск
```bash
cd Flex
python -m http.server 5500
# открыть http://localhost:5500
```

## Деплой на Vercel
1. Создать репозиторий на GitHub и запушить содержимое папки `Flex`.
2. В Vercel: «Add New → Project» → импортировать репозиторий.
3. Framework Preset: **Other** (статика), никаких build-команд. Deploy.

Альтернатива — перетащить папку `Flex` в Vercel CLI / дашборд (заливка без git).
